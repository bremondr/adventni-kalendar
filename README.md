# Adventní kalendář

Adventní herně šifrovací kalendář grafit.games.

## Obsah

Zatím prázdné; sem přibude plán, jednotlivé dny kalendáře, šifry a podklady.

## Jak přispívat

- Před začátkem práce udělej `git pull`.
- Pracuj na vlastní větvi a do `main` neposílej přímo; změny se slučují přes pull request.
  GitHub tuto větev technicky nechrání (soukromý repozitář na bezplatném plánu), takže jde jen o dohodu.
- Commituj po malých krocích a s výstižnou zprávou.
- Soubory jsou obyčejný Markdown (UTF-8, LF). Používej standardní Markdown odkazy a přílohy
  ukládej do této složky.
- Nepřidávej sem soukromé poznámky, přístupové údaje ani osobní data.
